# PDFダウンロード販売（回数・期間の制限、会員クーポンつき）画面見本

ランサーズ案件 5631177 に応募するための見本（2026-11-17 作成）。**画面と流れだけの自主制作で、決済・ダウンロード・WordPress は動きません（動作イメージ）。** 商品の中身は汎用（依頼専用の制作物にしない）。

## 開き方
`index.html` をダブルクリックしてブラウザで開く（外部の読み込みなし・1ファイル）。上のボタンで 1〜6 の画面を切り替えられます。

| 画面 | 中身 |
|---|---|
| 1 商品 | サンプル資料集（PDF・約500ページ）3,000円、「購入後30日間・3回まで」の表示 |
| 2 購入 | クーポン欄に `MEMBER1000` で 1,000円引き → 2,000円 |
| 3 決済 | カード番号欄、Apple Pay / Google Pay 風ボタン（「動作イメージのため決済は行われません」と表示） |
| 4 完了 | 「決済が完了したので、ダウンロードできます」、期限と回数 |
| 5 マイページ | 残り回数 3→2→1→0 と期限。0回でボタンが押せなくなる |
| 6 管理画面 | WooCommerce の商品データ（ダウンロード制限・期限）とクーポン設定を模した画面。「更新」で 1〜5 に反映 |

本番の想定構成：WordPress ＋ WooCommerce（無料）＋ Stripe（WooCommerce Stripe Payment Gateway）。回数・期限・クーポンは WooCommerce の標準機能で設定できる項目に寄せている。

## 画面画像（ポートフォリオ用）
`画面画像/` に6枚（1200px幅）。撮り直す時は、ローカルで配信して `index.html#cart:coupon`（クーポン適用済み）、`#mypage:0`（残り0回）のように画面と状態を指定して撮る。

**タイトル（43字）**
PDF資料のダウンロード販売サイトを、回数・期間の制限と会員クーポンつきで制作しました

**説明文**
自主制作の作品です。PDF資料をダウンロード販売する時の、購入から受け取りまでの画面と流れを作りました。決済は動作イメージです（実際の決済は行いません）。

・商品ページ：価格と「購入後30日間・3回までダウンロードできます」の表示
・購入画面：会員向けクーポンコードを入れると1,000円引きになる計算
・決済画面：カード入力欄、Apple Pay・Google Pay のボタン（動作イメージ）
・購入完了：決済が終わった後にだけダウンロードできる流れ
・マイページ：残りのダウンロード回数と期限を表示し、上限に達するとボタンが押せなくなる
・管理画面：商品ごとのダウンロード回数・期間、クーポン（コード・割引額・使える人）の設定

WordPress の WooCommerce と Stripe で構築することを想定し、管理画面の設定項目もそれに合わせています。
